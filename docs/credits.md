# Asset credits

All 3D models, materials, environment maps, and window views in the room themes come from
[Poly Haven](https://polyhaven.com). Poly Haven publishes them under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). CC0 does not require
attribution. We credit the authors as a courtesy.

`assets/manifest.json` records, for each asset: the source page, the authors, the license,
and the URL, SHA-256, and size of every downloaded file. `npm run assets` in `apps/web`
downloads and converts the assets again from `assets/sources.json`, and checks every hash.

Assets in this version: 61, 36.8 MiB after conversion (KTX2 textures, Meshopt geometry).
